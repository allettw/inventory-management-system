# Inventory Management System

A Python-based inventory management system for tracking products, stock levels, sales, and business operations.

## About the project

This project aims to develop an inventory management application for a small business focused on selling cleaning products and garbage bags.

The application is being developed progressively, starting with a command-line prototype and evolving into a more complete system.

## Current features

- Product registration and management.
- Stock control.
- Product search by code and category.
- Sales registration.
- Sales history.
- Basic inventory and sales reports.

## Technologies

- Python
- Object-Oriented Programming (OOP)
